# AxionMinds Portfolio Website

A responsive, static portfolio site built with HTML, CSS, and a small amount of JavaScript. It is designed for GitHub Pages and intentionally omits university names and location details.

## Publish with GitHub Pages

1. Sign in to GitHub and open your `AxionMinds` account.
2. Create a **public** repository named `axionminds.github.io` (if it does not already exist).
3. Upload `index.html`, `styles.css`, `script.js`, and this `README.md` to the repository root.
4. Open **Settings → Pages**.
5. Under build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for the Pages deployment to finish. Your expected address is `https://axionminds.github.io/`.

## Before publishing

- Review the experience section and adjust descriptions so every line accurately reflects your work.
- Verify the status of every credential. The CompTIA A+ card currently asks you to update its status before publishing.
- Add links to project repositories only after the projects exist and are ready to share.
- Do not upload a résumé or files containing personal details unless you have reviewed them for privacy.
- LinkedIn may contain details that are not shown on this site; review your public LinkedIn profile separately.
- This site links to LinkedIn only and does not publish a phone number, email address, or location.

## Customize

- Edit text and sections in `index.html`.
- Change colors, spacing, and layout in `styles.css`.
- Change mobile navigation behavior in `script.js`.
- Replace the CSS-generated hero graphic with a custom brand image later if desired.

This is a static website; it does not collect form submissions or store visitor data.
